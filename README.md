# workwithruss

One-page portfolio for **Russel Hernandez** — freelance software developer and automation specialist.

Live target: [https://workwithruss.vercel.app](https://workwithruss.vercel.app)

## Stack

Static HTML. No build step.

## Deploy on Vercel

1. Open [vercel.com](https://vercel.com) and sign in with GitHub (`steadywithshane`).
2. **Add New Project** → import `workwithruss`.
3. Framework preset: **Other**. Output/root: leave default.
4. Set the project name to `workwithruss` so the URL is `workwithruss.vercel.app`.
5. Deploy.
